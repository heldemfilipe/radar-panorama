# Um feed por linha. Linhas com # são ignoradas.
#
# Formatos aceitos:
#   https://site.com/feed/                 -> RSS normal
#   https://site.com/feed/ | Nome          -> RSS com nome fixo no episódio
#   gnews: "Rio Claro" SP | Nome           -> busca no Google Notícias
#   sitemap: <url com {data}> <trecho> | Nome -> sitemap diário
#   https://site.com/feed/ | Nome | 72h    -> janela maior que 24h, pra fontes
#                                             que postam pouco (o histórico
#                                             impede repetir notícia)
#   https://site.com/feed/ | Nome | 24h | politica
#                                          -> 4º campo OBRIGATÓRIO aqui: diz a
#                                             qual bloco do episódio a fonte
#                                             pertence (veja as tags abaixo)
#
# TAGS (cada uma é um bloco do episódio):
#   politica    -> Política (Brasil, MBL, Partido Missão...)
#   geopolitica -> Geopolítica
#   economia    -> Economia & Mercados (Brasil e mundo, bolsas, ações, ETFs, câmbio)
#   trabalho    -> Trabalho & Renda (empregos novos, ganho por hora, onde está o dinheiro)
#   esportes    -> Esportes (Santos FC, Manchester City)
#   local       -> Rio Claro & Região
#   ciencia     -> Ciência & Sociedade (tecnologia, infraestrutura, ciência, saúde,
#                  educação, segurança, filosofia, comportamento)
#   fe          -> Fé & Teologia (teologia pentecostal, comentários bíblicos,
#                  arqueologia bíblica)
#
# Pra adicionar um site: procure "nome-do-site RSS" no Google e cole a URL
# aqui — mas TESTE antes (alguns sites "chutados" devolvem 404 ou feed vazio).
# Se o site bloquear o GitHub (403/429), o script busca as notícias dele
# pelo Google Notícias sozinho — não precisa trocar a URL.
